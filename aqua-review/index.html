Fountain Music & Animation Studio

Music editing • Nozzle groups • Timeline • Animation preview

1. Fountain Image & Nozzle Setup

Yahan apni original fountain layout image select karein. Image ke upar click karke nozzle dots add karein. Har dot ek fountain jet ko represent karega.

Nozzles: 0 | Selected: 0

2. Nozzle Groups

Dots select karein, group ka naam likhein aur Create Group dabayein. Misal: Centre, Centre Line, Right Side. Maximum 100 groups.

3. Music Tracks

Track A aur Track B alag-alag music files hain. WAV ya MP3 upload karein. Demo ke liye 60-second sample music bhi generate kar sakte hain.

4. Music Waveform

Waveform par click karke music ka playhead set karein. Selected track ki waveform yahan nazar aayegi.

Load a track to view waveform

5. Animation Builder

Selected group ke liye animation event banayein. Start time, spray duration, pause aur height apni marzi se set karein.

6. Animation Timeline

Har group ki timeline lane hai. Event par click karke uski settings load karein. Phir Update selected event se timing change karein.

7. Live Fountain Preview

Play dabane se loaded music aur group-wise fountain animation saath chalegi. Stop se preview ruk jayega.
