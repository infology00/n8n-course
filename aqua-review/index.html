Fountain Music & Animation Studio

Fixed original fountain layout · Select jets · Create coloured groups · Build music-synced sequences

1. Original Fountain Layout & Jet Selection

Yahi original image fixed hai—image change/upload ka option nahi. Image ke colored nozzle dots par click karke individual jets select karein. Multiple dots select kar sakte hain; selected dots white ring se highlight honge.

Detecting jets…

Tip: click dot to toggle selection. Shift-click also adds/removes dots. A group’s colour is applied to every jet in that group—not separate per-jet colours.

2. Groups & Group Colours

Selected jets ko ek named group mein rakhein. Group ka colour picker badalne se us group ke tamam selected jets ka display colour badlega. Maximum 100 groups.

3. Music Tracks

Track A aur B independent hain. WAV/MP3 upload karein, ya 60-second demo generate karein. Fountain image yahan change nahi hoti.

4. Music Waveform

Active track ki waveform. Waveform par click karke preview ka start/playhead set karein.

5. Animation Event Editor

Har event ek group ko music ke kisi hissa mein spray karwata hai. Start, duration, pause, height aur pattern set karein. Timeline se event select karke Update karein.

6. Auto Animation Builder & Timeline

Auto-build selected groups ko music duration mein arrange karta hai. Sequential = ek group ke baad doosra; overlap = staggered groups; together = sab ek saath. Baad mein har event manually edit karein.

7. Live Preview

Play se loaded tracks aur scheduled group jets saath preview honge. Preview visual demonstration hai; abhi final production WAV export/control output included nahi.
