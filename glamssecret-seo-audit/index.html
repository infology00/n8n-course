05 · Delivery plan

Six days. Three controlled phases.

Each phase has a clear output, so the project keeps moving toward launch readiness.

Days 1–2 · Baseline

Pre-Audit

  • Current-site crawl
  • URL inventory & representative page set
  • Title / description review
  • Canonical & schema review
  • Image / ALT review
  • Robots / sitemap / indexability
  • Performance baseline
Days 3–4 · Protection

Migration Review

  • Current vs staging comparison
  • Changed URL identification
  • Redirect mapping
  • Template SEO comparison
  • Canonical / schema checks
  • Image and frontend SEO review
  • Launch-risk checklist
Days 5–6 · Proof

Post-Audit

  • Production re-crawl
  • Baseline comparison
  • Regression detection
  • Redirect verification
  • Indexability verification
  • Final priority report
  • Launch recommendations
