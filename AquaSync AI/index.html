Technology stack

Tools we propose to use

Final selection depends on the client's software, file format, controller, and deployment needs.

⌘

Web portal

React / Next.js for a responsive interface, cue editor, and project management.

∿

Audio analysis

Python audio tooling such as librosa, plus Web Audio API for browser playback and analysis.

▦

Timeline editor

A custom timeline to display, select, edit, add, and delete suggested cues.

◈

Optional 3D preview

Three.js can visualize a mapped fountain layout if dimensions and nozzle positions are supplied.

⇄

File integration

A format-specific import/export adapter after inspecting a sample project file.

⚙

Future controller link

PLC, DMX, or other hardware integration is a separate phase requiring technical validation.

Frontend: React / Next.js Audio: librosa / Web Audio API 3D: Three.js (optional) Export: JSON / CSV draft

Project kickoff

What we need to begin

Client to provide

  • A sample show/project file
  • The matching music file
  • Current software name and version
  • Software access or screen-share walkthrough
  • Import/export instructions, if available
  • Fountain layout and nozzle/group map, if available
  • Controller model and protocol details for future hardware work

Key assumptions

  • AI-generated cues are suggestions for human review.
  • Music analysis cannot determine exact water height by itself.
  • Compatibility with proprietary software is not yet confirmed.
  • 3D mapping is optional and requires real fountain layout data.
  • Live hardware control requires a separate safety review and qualified testing.
